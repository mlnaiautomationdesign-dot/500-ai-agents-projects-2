Getting Started

Welcome to the AI Agents Marketplace! This guide will help you get started with purchasing and integrating AI agents into your applications.

Quick Start

  1. Create an Account: Sign up at signup page
  2. Browse Catalog: Explore our agent catalog
  3. Purchase Agent: Select and purchase the agents you need
  4. Get API Key: Access your API key from the dashboard
  5. Integrate: Use our API to integrate agents into your application

API Reference

Base URL

https://api.aiagentsmarketplace.com/v1

Authentication

All API requests require authentication using a Bearer token:

Authorization: Bearer YOUR_API_KEY

Endpoints

GET /agents

Retrieve a list of all available agents

curl -X GET https://api.aiagentsmarketplace.com/v1/agents \
  -H "Authorization: Bearer YOUR_API_KEY"

POST /agents/:id/execute

Execute an agent with provided input

curl -X POST https://api.aiagentsmarketplace.com/v1/agents/123/execute \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"input": "Your query here"}'

GET /user/purchases

Get list of purchased agents

curl -X GET https://api.aiagentsmarketplace.com/v1/user/purchases \
  -H "Authorization: Bearer YOUR_API_KEY"

Integration Guide

JavaScript/Node.js Example

const axios = require('axios');

const API_KEY = 'your_api_key_here';
const BASE_URL = 'https://api.aiagentsmarketplace.com/v1';

async function executeAgent(agentId, input) {
  try {
    const response = await axios.post(
      `${BASE_URL}/agents/${agentId}/execute`,
      { input },
      {
        headers: {
          'Authorization': `Bearer ${API_KEY}`,
          'Content-Type': 'application/json'
        }
      }
    );
    return response.data;
  } catch (error) {
    console.error('Error:', error.response.data);
  }
}

// Usage
executeAgent(123, 'Generate a blog post about AI')
  .then(result => console.log(result));

Python Example

import requests

API_KEY = 'your_api_key_here'
BASE_URL = 'https://api.aiagentsmarketplace.com/v1'

def execute_agent(agent_id, input_text):
    headers = {
        'Authorization': f'Bearer {API_KEY}',
        'Content-Type': 'application/json'
    }
    
    data = {'input': input_text}
    
    response = requests.post(
        f'{BASE_URL}/agents/{agent_id}/execute',
        json=data,
        headers=headers
    )
    
    return response.json()

# Usage
result = execute_agent(123, 'Generate a blog post about AI')
print(result)

Code Examples

Complete Integration Example

Here's a complete example of integrating a customer support agent:

// Initialize the AI Agent
const AIAgent = require('ai-agents-sdk');

const agent = new AIAgent({
  apiKey: process.env.AI_AGENTS_API_KEY,
  agentId: 'customer-support-bot'
});

// Handle customer query
async function handleCustomerQuery(query) {
  try {
    const response = await agent.execute({
      input: query,
      context: {
        customerHistory: true,
        sentiment: true
      }
    });
    
    return {
      answer: response.output,
      confidence: response.confidence,
      suggestions: response.suggestions
    };
  } catch (error) {
    console.error('Error processing query:', error);
    return { error: 'Unable to process query' };
  }
}

// Usage in Express.js
app.post('/api/support', async (req, res) => {
  const { query } = req.body;
  const result = await handleCustomerQuery(query);
  res.json(result);
});
